## 2. 条件镜头说明

- **镜头 8 已转必拍**：星闪本地链路 11-05 实测跑通（主控 LCD `SLE:ON`、81 条连续报文），LCD 状态行特写是现成可视化素材。C 板断线自动重连日志素材已备好（HANDOFF §8），保留作"鲁棒性"加分项

## 3. 拍摄技巧

- 板子镜头：桌面俯拍 + 一盏台灯，LCD 横幅要正对镜头；蜂鸣声用现场收音（是演示点，别配乐盖掉）
- cloud_check 输出：PowerShell 字体调到 24pt+ 再录屏，或重定向到记事本放大
- 每个镜头多拍 2-3 条；报警瞬间的镜头提前彩排一次触发时机
- App 操作速度放慢 20%，观众要看清卡片弹出

## 4. 后期与压缩（≤100MB）

```bash
# 1080p→720p 压到 ~90MB（4.5min）
ffmpeg -i raw.mp4 -vf scale=1280:-2 -c:v libx264 -crf 28 -preset slow -c:a aac -b:a 96k final.mp4
# 体积超了就 crf 再 +2（30/32），低于 70MB 可以 -2 换画质
```

字幕：口播全部配字幕（比赛评审常静音看）；烧录前用 ffprobe 确认 `final.mp4` < 100MB。
